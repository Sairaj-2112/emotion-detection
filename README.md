# Emotion Detection Application

## Project Description

This project is an Emotion Detection application developed using Python,
Watson NLP and Flask.

The application analyzes a given text and identifies the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion in the given text.

## Technologies Used

- Python
- Watson NLP
- Flask
- HTML
- CSS
- Requests

## Project Features

- Emotion detection from text
- Dominant emotion identification
- REST-style Flask endpoint
- Unit testing
- Error handling
- Static code analysis
